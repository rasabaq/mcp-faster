How the heat score works

Four checks, each from 0 to 100%. We multiply them. One weak part pulls the whole score down, on purpose: a server that never connects is not healthy, however fast it is.

heat = connects × stays up × gets used × few errors

Questions

What does mcp-faster stats read?

The Claude Code logs and chat records already on your computer. For this page that was log files and chat records from one machine.

What is the heat score?

A score from 0 to 100 for each server: connects × stays up × gets used × few errors. Servers that only show up in chat records have no connect logs, so they count as connecting and staying up.

What do the labels mean?

Each server gets one label: its biggest problem, checked in this order.

    Which way should I use?

    In our runs, the local mirror: of right, s per task and for runs. It needs a one-time copy of the data. Code mode came second on cost, at .

    What does the proxy do?

    It sits between your agent and your servers. It has three layers: consolidate, cache and compact. It can also start a server only when the first call needs it. You set it up in proxy.json.

    What do I need to run it?

    Node 24 or newer. stats and mine only read your logs. bench calls a real model, so it needs a model API key.
